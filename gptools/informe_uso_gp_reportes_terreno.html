1. Resumen ejecutivo

La solución genera el formulario corporativo F-MA-018 — Reporte de Terreno Operacional en PDF a partir de un registro de Survey123/Feature Service. Integra datos principales, relaciones, acciones, cierres, mapas e imágenes; entrega el PDF descargable y solicita su almacenamiento en SharePoint mediante Power Automate.

Nombre RESTDirecciónTipoObligatorioDescripción

output_pdfSalidaGPDataFileDerivadoArchivo PDF generado y descargable desde el resultado del job.

Importante: el parámetro ObjectID es texto para facilitar su consumo desde widgets y webhooks, pero su contenido debe representar un identificador entero válido cuando se utiliza el modo manual.

4. Modos de ejecución

Modo manual
ObjectID informado

Recomendado para ArcGIS Pro, widgets y solicitudes directas. La herramienta consulta exactamente el registro indicado, genera el PDF, intenta publicarlo en SharePoint y devuelve ambas salidas.

Modo automático
ObjectID vacío

Diseñado para Survey123/webhooks. Selecciona el registro con last_edited_date más reciente y sólo lo procesa si pertenece a la ventana temporal configurada.

Ventana temporal del modo automático

La comparación se realiza con marcas de tiempo Unix en milisegundos, en UTC. Por ello no se resta manualmente la diferencia horaria de Chile ni se depende de la zona horaria configurada en ArcGIS Server. El valor predeterminado es de 15 minutos y puede ajustarse con RT_AUTO_LOOKBACK_MINUTES.

Sin registros recientes: es una ejecución correcta sin trabajo pendiente. La herramienta informa la situación, deja vacíos output_pdf y sharepoint_url, y no marca el job como fallido.
Concurrencia: el modo automático selecciona la última edición global. Si se reciben varias encuestas casi simultáneas, la integración debe ejecutar el job inmediatamente y monitorear duplicados. Cuando el sistema llamador conoce el ObjectID, el modo manual es determinista y preferible.

5. Consumo mediante ArcGIS REST API

Al ser un servicio asíncrono, el cliente debe enviar un job, consultar su estado y finalmente recuperar cada salida. Los ejemplos omiten credenciales deliberadamente.

5.1 Enviar un reporte manual

POST {TASK_URL}/submitJob
Content-Type: application/x-www-form-urlencoded

f=json
token=<TOKEN_PORTAL>
object_id=2174

5.2 Activar el modo automático

POST {TASK_URL}/submitJob
Content-Type: application/x-www-form-urlencoded

f=json
token=<TOKEN_PORTAL>
# object_id se omite o se envía vacío

5.3 Ejemplo Python

import time
import requests

TASK_URL = (
    "https://sig.aminerals.cl/vector/rest/services/"
    "CL_MLP_GMA_ReportesRT/GPServer/Generar%20reporte%20de%20terreno"
)
token = "<TOKEN_PORTAL>"

# Para modo automático, eliminar object_id o asignar una cadena vacía.
job = requests.post(
    f"{TASK_URL}/submitJob",
    data={"f": "json", "token": token, "object_id": "2174"},
    timeout=60,
).json()
job_id = job["jobId"]

while True:
    status = requests.get(
        f"{TASK_URL}/jobs/{job_id}",
        params={"f": "json", "token": token}, timeout=30,
    ).json()
    if status["jobStatus"] in {"esriJobSucceeded", "esriJobFailed", "esriJobCancelled"}:
        break
    time.sleep(2)

if status["jobStatus"] != "esriJobSucceeded":
    raise RuntimeError(status.get("messages", status))

pdf_result = requests.get(
    f"{TASK_URL}/jobs/{job_id}/results/output_pdf",
    params={"f": "json", "token": token}, timeout=30,
).json()
sp_result = requests.get(
    f"{TASK_URL}/jobs/{job_id}/results/sharepoint_url",
    params={"f": "json", "token": token}, timeout=30,
).json()

print(pdf_result)  # URL temporal de descarga
print(sp_result)   # URL del archivo en SharePoint
Descarga: la URL del GPDataFile puede requerir el mismo token. El cliente debe descargarla mientras el resultado del job siga disponible según la política de limpieza de ArcGIS Server.

6. Contenido y salidas del reporte

La composición recorre la estructura relacional del levantamiento: registro principal → instalaciones o áreas → acciones → cierres de acción, además del cierre general. Los mapas quedan centrados, las tablas comparten el ancho del bloque de imágenes y las fotografías se distribuyen en una cuadrícula adaptable.

SalidaComportamientoUso recomendado
PDF del jobSe genera en el directorio temporal administrado por ArcGIS Server.Descarga directa desde widget, ArcGIS Pro o consumidor REST.
URL SharePointSe calcula y retorna como salida aun cuando Power Automate no pueda confirmar una sobrescritura.Navegación al repositorio documental y almacenamiento del enlace.

Clasificación de destino en SharePoint

  • Reporte cerrado: carpeta base de Reportes de Terreno.
  • Reporte en proceso: subcarpeta En Tratamiento.

Sitio base: https://aminerals.sharepoint.com/sites/SIG_AMSA/MLP/GMA.

Semántica de la URL: la salida representa el destino esperado. Una URL informada no sustituye la confirmación del flujo cuando SharePoint rechaza o demora una sobrescritura. Para trazabilidad, conservar la respuesta de Power Automate y el Job ID.

8. Procedimiento de publicación y validación

Antes de publicar

  • Validar la toolbox en el entorno Python de ArcGIS Pro.
  • Generar un PDF con ObjectID conocido.
  • Confirmar acceso al Feature Service, relaciones y adjuntos.
  • Verificar plantilla/logos y salida de mapas.
  • Probar Power Automate sin exponer su URL en mensajes.

Después de publicar

  • Confirmar que la tarea aparece como asíncrona.
  • Ejecutar modo manual y descargar output_pdf.
  • Validar sharepoint_url y existencia del archivo.
  • Ejecutar modo automático con una edición reciente.
  • Ejecutar nuevamente sin edición reciente y confirmar éxito sin salidas.
Actualizaciones: cuando cambie código, dependencias o recursos, se debe sobrescribir el servicio, comprobar la fecha de modificación del Item y repetir las pruebas de aceptación. Mantener el mismo Item ID evita romper consumidores existentes.

10. Seguridad, auditoría y soporte

  • Mantener el Item y el servicio compartidos únicamente con grupos o cuentas autorizadas.
  • No incluir tokens, contraseñas, URL firmada de Power Automate ni contenido Base64 en logs.
  • Registrar Job ID, ObjectID seleccionado, modo, nombre del PDF, duración y resultado del flujo.
  • Aplicar rotación de credenciales sin modificar consumidores del GP Service.
  • Monitorear espacio temporal, tiempos de generación, errores de adjuntos y fallos del flujo.

Criterio de éxito: el job finaliza en esriJobSucceeded; para una solicitud con registro válido existe un PDF descargable, y la URL SharePoint se entrega como segunda salida. En modo automático sin novedades, el éxito se expresa mediante mensajes y salidas vacías.
